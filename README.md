## 一、它能做什么

一个完整的个人主页，前台是这个样子：

- **液态玻璃界面**——毛玻璃卡片、悬停微动效、滚动淡入、背景视差
- **头像 + 名字 + 关于我**，背景图可换
- **音乐播放器**——右下角悬浮，显示封面、歌名和进度环，支持多首，
  可按顺序或随机播放，也可以整个关掉
- **社交链接**——顶栏和左侧栏展示，自带 15 个图标，也能自己上传
- **GitHub 集成**——填个用户名，自动展示你的开源项目卡片和贡献热力图
- **电报频道卡片**——「加入我的频道」，点击直达
- **页脚**——放备案号或版权信息，颜色和透明度随你调

后台是分开的，藏在你自己设的「安全入口」后面：

- 界面上的每一项都能改，改完刷新前台立刻生效
- 支持上传头像、背景图、音乐（拖拽排序、配封面）
- 5 个动画效果可以一个一个单独关
- 密码用 PBKDF2 加盐哈希存储，数据库里没有明文
- 访客访问你的域名只会看到主页，**不会发现后台的存在**

一句话：这是你自己的网站，但不用碰代码。

## 二、准备工作

**只需要两样东西，全程用手机就能完成，不需要电脑：**

1. **GitHub 账号** —— 用来放代码。没有的话去 <https://github.com/signup> 注册，一分钟的事。
2. **Cloudflare 账号** —— 用来部署。没有的话去 <https://dash.cloudflare.com/sign-up> 注册，也是免费的。

就这些。整个部署过程你在手机浏览器里点几下就能搞定，不用装任何软件，
不用打开终端，不用敲命令。

> 唯一的例外是「上传图片和音乐」需要先开通 R2 存储，这一步在
> Cloudflare 控制台点几下就行，同样不需要电脑（见第三节第 4 步）。

## 三、部署（纯网页操作，手机也能做）

### 第 1 步：Fork 这个仓库

打开仓库页面，点右上角的 **Fork** 按钮，选你自己的账号。

几秒钟后你就有了一份属于自己的完整代码，在 `https://github.com/你的用户名/grwz`。
以后想改代码、想同步我的更新，都在你自己的仓库里操作，互不影响。

> **如果你拿到的是一份文件夹（不是从 GitHub Fork），**
> 那需要先把它传到自己的 GitHub 上。具体步骤见
> [UPLOAD.md](UPLOAD.md)——里面写了网页上传的注意事项，
> 照做就行，手机也能操作。

### 第 2 步：连接 Cloudflare 部署

1. 打开 <https://dash.cloudflare.com/> 并登录
2. 左侧选 **Workers & Pages** → **Create** → 选 **Workers** 标签页
3. 点 **Connect to Git**（或 "Import a repository"）
4. 授权 Cloudflare 访问你的 GitHub，选中你的仓库
5. **展开 Build settings**，把 **Deploy command** 改成：

   ```
   npx wrangler deploy
   ```

   （默认就是这行，确认一下即可）

6. 点 **Deploy**

等一两分钟，Cloudflare 会给你一个网址，类似：

```
https://grwz.你的用户名.workers.dev
```

打开它——官网已经上线了。第一次打开会显示「网站还在准备中」，这是正常的，
因为还没初始化。

> **数据库不用手动建。** 网站第一次被访问时会自动建好所有数据表和默认配置，
> 你完全不用碰任何 SQL。

---

### ⚠️ 部署失败了怎么办

#### 报错：`The entry-point file at "src/worker.js" was not found`

意思是 **`src/` 文件夹没上传成功**。

用 GitHub 网页拖文件夹上传时，嵌套子目录经常会漏掉。请去你的仓库页面
确认能看到这三个文件夹：**`src/`、`public/`、（可选）`test/`**。

看不到就重新上传，要点：

- 一次拖**整个文件夹**，不要只拖里面的文件
- 上传后**务必回到仓库首页刷新看一眼**，确认 `src/` 里还有 `worker.js`、
  `lib.js`、`migrate.js` 和 `routes/` 子文件夹
- `src/` 里如果只显示文件、没有 `routes/` 文件夹，就是漏了

> 更稳妥的办法：在你自己的仓库页面点 **Add file → Upload files**，
> 把整个文件夹**分几次**传（先传 `src/`，再传 `public/`），
> 每次传完都确认一下结构。

#### 报错：`database_id` 相关 / 找不到数据库

`wrangler.toml` 里的 `database_id` 默认是占位符。最省事的解决办法：

1. 在 GitHub 网页上打开 `wrangler.toml`，点铅笔图标编辑
2. 把 `database_id = "REPLACE_WITH_YOUR_D1_DATABASE_ID"` **这一行整个删掉**
3. 提交后回到 Cloudflare 重新部署

然后在 Cloudflare 控制台：**你的 Worker → Settings → Bindings →
Add binding → D1 database**，变量名填 `DB`，选一个数据库
（没有就点 Create 新建一个），保存。

#### 其他构建失败

在你电脑上（如果 Node.js 可用）跑一下自检，它会直接告诉你缺什么：

```bash
npm run check
```

### 第 3 步：初始化后台

浏览器访问：

```
你的网址/backstage
```

比如 `https://grwz.你的用户名.workers.dev/backstage`。

接下来按第四节走一遍向导就行。

### 第 4 步（想传图片和音乐再做）：开通 R2 存储

网站本身已经能用了，只是暂时不能上传头像、背景图和音乐。

要开通的话，在手机浏览器里：

1. 打开 <https://dash.cloudflare.com/> → 左侧 **R2**
2. 点 **Create bucket**，名字填 `grwz-assets`（名字随便起，记住就行）
3. 首次使用会要求绑一张卡验证身份，**免费额度内不会扣钱**（见第七节）
4. 回到 **Workers & Pages** → 选中你的 Worker → **Settings** → **Bindings**
5. 点 **Add binding** → 选 **R2 bucket** → 变量名填 `BUCKET`（必须一模一样）
   → 存储桶选刚才建的 `grwz-assets`
6. 保存后刷新你的网站，就能上传了

> 后台顶部会有一条提示条提醒你这件事，绑好之后它会自动消失。

## 附：如果你有电脑，也可以用命令行

命令行不是必需的，只是有些人更喜欢。前提是装好
[Node.js](https://nodejs.org/)（选 LTS 版）。

```bash
git clone https://github.com/你的用户名/grwz.git
cd grwz
npm install
npx wrangler login
npx wrangler r2 bucket create grwz-assets
npm run deploy
```

用这种方式的话，`wrangler.toml` 里的 `database_id` 需要你手动填一次：

```bash
npx wrangler d1 create grwz-db
```

把输出的 `database_id` 复制到 `wrangler.toml` 里对应那行即可。
建表同样可以省略——Worker 会自动建。

## 四、初始化：第一次进入后台

### 第 1 步：打开后台入口

在浏览器里访问：

```
你的域名/backstage
```

> 例如 `https://grwz.pixric.workers.dev/backstage`

### 第 2 步：设置安全入口

页面会让你设置「安全入口」，也就是以后登录后台的地址。

- 至少 **5 位**
- 只能用字母、数字、下划线、中划线
- 建议别用 `admin`、`login` 这种一眼就能猜到的词

比如你填 `coas2024`，那么以后后台地址就是：

```
你的域名/coas2024
```

**请一定记住这个地址**（可以存到密码管理器里）。设好之后点「下一步」。

### 第 3 步：注册管理员

- 账号：至少 **3 位**
- 密码：至少 **6 位**（建议更长一些）

密码不会明文保存，而是用 **PBKDF2-HMAC-SHA256 加盐哈希 12 万次** 之后
再存进数据库的，谁都看不到原文——包括你自己。所以**忘了只能重置**。

### 第 4 步：看到「一切完成」

注册成功后会显示一个打勾的「**一切完成**」动画，停留 **4 秒**，
然后淡出，自动进入你刚设好的安全入口登录页。

用刚才的账号密码登录，就进后台了。

### 登录之后

以后每次进后台，只要访问 `你的域名/安全入口`，输入账号密码即可。

> 顺带一提：**如果访问的地址不是正确的安全入口**，比如别人随便输一个
> `你的域名/abc`，或者直接访问你的主页 `me.coas.top`，
> 看到的都是正常的个人主页，不会暴露后台的存在。

## 五、后台功能详解

后台左侧有 7 个菜单，逐个说明。

### 1. 关于我

- **头像**：点击上传。建议用正方形图片，会自动裁成圆形。
  不上传的话，会自动用你名字的首字母做渐变占位块。
- **背景图**：整站背景。建议 1920×1080 以上的横图。
  不上传时用内置的淡紫渐变。
- **网站名称 / 名字**：显示在顶栏和左侧大字。
- **副标题 / 用户名**：显示在名字下方的小字。
- **关于我**：首页「关于我」卡片里的正文，支持换行。

改完点保存，刷新前台就能看到。

### 2. 外观与动画

见 [第六节](#六动画开关说明)。

这里还能控制：

- **启用音乐功能** —— 关掉后前台完全不显示播放器。
- **播放顺序** —— 「默认顺序」按音乐列表顺序播；「随机顺序」每次打开随机打乱。
- **电报频道** —— 「加入我的频道」卡片的开关、标题、下方灰色小字和跳转链接。
  默认已经填好 <https://t.me/COASCN>。

### 3. 音乐

- 点击虚线框选文件，或直接把音频**拖进去**。
- 支持多选，会一个一个上传并显示进度。
- 支持 mp3 / m4a / wav / flac / ogg 等常见格式。
- **单文件最大 96MB，最多 50 首。**

上传后可以：

- 直接改歌名和歌手（点输入框改，然后点 💾 保存）
- 点 📷 上传这首歌的封面
- 点 🗑 删除
- 拖左侧的 ⠿ 手柄调整顺序

> 前台播放器右下角显示封面、歌名和进度环。
> 播完自动下一首；只有一首时会单曲循环。

### 4. 社交链接

- 填**显示名称**和**链接地址**，然后选一个图标。
- 内置图标：X、Telegram、GitHub、爱发电、哔哩哔哩、微博、邮箱、QQ、
  Steam、YouTube、Discord、Instagram、知乎、微信，以及一个通用链接图标。
- 也可以点「或上传自定义图标」用自己的图片。
- 添加后可以拖动排序、点眼睛图标临时隐藏、点 🗑 删除。

> **建议最多 5 个**（只是建议，不强制）。加太多顶栏会挤，手机上尤其明显。
> 超过 5 个时后台会提示你，但不会拦着。

这些链接会同时出现在**顶栏**（只有图标）和**左侧栏**（图标 + 文字）。

### 5. GitHub

- 填你的 **GitHub 用户名**就行，不用填完整网址。
  比如你的主页是 `github.com/octocat`，那就填 `octocat`。
- **展示开源项目卡片**：自动读取你的公开仓库，显示名称、简介、语言、星标数和 fork 数。
- **展示贡献图**：显示那张绿色的提交热力图。

这两个可以单独开关。

### 6. 页脚 / 备案

放在网站**最下方**的一行字，适合放备案号或版权信息。

- **显示文字** —— 比如 `京ICP备00000000号-1`。留空就不显示。
- **点击跳转链接** —— 可选，比如工信部备案系统地址。
- **文字颜色** —— 默认灰色 `#8a8a8e`，可以调色盘选，也可以直接填色值。
- **透明度** —— 默认 55%，拖到 0 就完全看不见，拖到 100% 就完全不透明。

调整时下面有实时预览，所见即所得。

### 7. 安全与账号

- **安全入口** —— 改后台地址。改完会立刻跳转到新地址，
  **旧地址马上失效**，记得用新地址重新登录。
- **修改账号密码** —— 需要先输入当前密码。改密码后其他设备的登录会失效。
- **存储占用** —— 看用了多少空间。
- **清空全部上传** —— 会删掉所有音乐、头像、背景图和自定义图标。
  需要输入 `DELETE` 确认，**不可撤销**，慎用。

## 六、动画开关说明

在「外观与动画」里，这 5 个动画可以**单独**开关，互不影响：

| 开关 | 效果 | 关掉之后 |
|---|---|---|
| **网站打开时的开场效果** | 进入页面时整页从高斯模糊聚焦清晰，并轻微缩放 | 页面直接清晰出现 |
| **背景视差移动与缩放** | 滚动时背景缓慢跟随，滚动中轻微放大 | 背景静止不动 |
| **内容滚动入场** | 卡片进入视口时淡入 + 上浮 | 内容直接显示 |
| **头像悬停微动效** | 鼠标移到头像上，轻微放大并旋转 | 头像不动 |
| **播放器入场与呼吸效果** | 播放器出现时的入场动画，播放中轻微呼吸 | 播放器静止出现 |

> 如果你或访客的系统开启了「减少动态效果」（`prefers-reduced-motion`），
> 所有动画会自动禁用——这是无障碍规范，不用管它。

## 七、费用说明

全部使用 Cloudflare 免费额度，个人官网**基本不可能超出**：

| 项目 | 免费额度 | 你的官网大概会用 |
|---|---|---|
| Workers 请求 | 每天 10 万次 | 每天几十到几百次 |
| D1 数据库 | 5GB 存储、每天 500 万次读 | 存配置，几乎可忽略 |
| R2 存储 | 10GB | 几十首歌 + 图片，通常 1GB 以内 |
| R2 流量 | **免费**（上传下载都不收） | —— |

R2 最大的好处是**没有出网流量费**，这也是我选它而不是别的存储的原因。

只有在访客量非常大（每天十万级）时才需要考虑付费，到那时你也该高兴才对。

## 八、常见问题

**Q：部署后打开是「网站还在准备中」？**
A：正常的，说明还没初始化。去 `/backstage` 走一遍初始化就好。

**Q：`/backstage` 能一直访问吗？会有安全风险吗？**
A：初始化完成后，访问 `/backstage` 只会显示登录页，没有账号密码进不去。
如果你希望连登录页都藏起来，可以不管它——因为登录页本身不泄露任何信息。
真正的内容入口是你自己设的安全入口。

**Q：访客访问 `me.coas.top` 会看到后台吗？**
A：不会。只有访问正确的安全入口才会出现登录页，其他任何路径都显示正常主页。

**Q：上传音乐提示文件过大？**
A：单文件上限 96MB。这是 Cloudflare Workers 请求体 100MB 的硬限制，
留了 4MB 给表单开销。想放更大的歌，只能用外部直链（暂不支持）。

**Q：音乐不自动播放？**
A：浏览器普遍禁止自动播放有声内容，这是浏览器策略，不是 bug。
页面加载后会尝试自动播放，如果被拦截，**访客第一次点击页面的任意位置**
就会开始播放。播放器上的按钮随时可以手动控制。

**Q：想换域名怎么办？**
A：在 Cloudflare 控制台进入你的 Worker → Settings → Domains & Routes，
添加自定义域名即可。添加后记得在后台「安全入口」页面确认一下地址显示正确。

**Q：改了安全入口，忘记了，进不去后台？**
A：见下一节。

**Q：Fork 之后我改了代码，会影响原仓库吗？**
A：不会。Fork 出来的是你自己的一份完整副本，你在里面怎么改都行，
跟原仓库互不影响。以后如果我更新了代码，你在自己仓库页面点
**Sync fork → Update branch** 就能把新版本合并过来
（如果两边都改过同一处文件，可能会提示冲突，手动选一下保留哪边即可）。

**Q：一定要用电脑吗？我没有电脑。**
A：不需要。Fork、连接 Cloudflare、部署、开通 R2、初始化后台，
全程都能在手机浏览器里完成。数据库也不用手动建——网站会自动建好。
你只需要在手机上点几下。

**Q：可以传视频吗？**
A：不可以，上传接口只接受音频和图片，这是刻意的安全限制。

## 九、忘记安全入口怎么办

安全入口存在数据库里，可以在**手机浏览器**里直接改回来。

### 方法：用 Cloudflare 的 D1 控制台（推荐，手机可用）

1. 手机打开 <https://dash.cloudflare.com/> → 左侧 **D1 SQL database**
2. 点进你的数据库（叫 `grwz-db` 或类似的）
3. 点 **Console** 标签页
4. 在输入框里粘贴下面的 SQL，点 **Execute**

**查看当前安全入口：**

```sql
SELECT value FROM settings WHERE key = 'security_entry';
```

**重设安全入口**（把 `新入口` 换成你想要的，至少 5 位）：

```sql
UPDATE settings SET value = '新入口' WHERE key = 'security_entry';
```

**连账号密码也忘了**，就清空管理员重新初始化：

```sql
DELETE FROM admins;
DELETE FROM sessions;
UPDATE settings SET value = '0' WHERE key = 'initialized';
```

三条分三次执行，或者贴在一起点 Execute 也行。
然后访问 `你的网址/backstage`，会重新走一遍初始化流程。

> 注意：这只重置后台的登录信息，**不会**删除你上传的音乐和图片。

### 如果你有电脑，也可以用命令行

```bash
npx wrangler d1 execute grwz-db --remote \
  --command "SELECT value FROM settings WHERE key = 'security_entry'"
```

## 十、安全设计说明

顺便说明一下这个后台是怎么保护你的，你心里有个数：

- **密码哈希**：PBKDF2-HMAC-SHA256，随机盐，12 万次迭代。
  数据库被看到也拿不到密码原文。
- **会话**：登录后发一枚随机 token 存在 HttpOnly + Secure + SameSite=Strict
  的 Cookie 里，JS 读不到，14 天过期。
- **防暴力破解**：登录接口限制同一 IP 5 分钟内最多 8 次尝试。
- **防 CSRF**：Cookie 用 SameSite=Strict，跨站请求带不上凭据。
- **上传校验**：音乐只收 `audio/*`，图片只收 `image/*`，并且按扩展名推断真实类型，
  防止有人上传脚本文件。
- **路径安全**：读取文件的接口会拒绝 `..`，防止目录穿越。
- **隐蔽性**：非安全入口的路径一律当作普通前台请求，不泄露后台存在。

唯一需要你自己守住的就是：**安全入口地址 + 账号 + 密码**，别设太简单。
